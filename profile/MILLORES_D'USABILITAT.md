# Usability Improvements Documentation (UI/UX) - Front-End

## Documentation
In this document you will find information about the usability improvements made to enhance the user experience (UX).
You will find the improvements made compared to the first versions, recently incorporated improvements and proposals for future improvements.

## Progressive Usability Improvements
Throughout the sprints we have been improving the visual quality. At the beginning of development, the visual side was very simple and used very generic colours, which made it unattractive.
At first we were using the browser's default alerts, which gave a negative impression. We changed this to use custom toasts instead.
During sprints 4 and 5, a visual overhaul was carried out, modifying the colours, sizes and animations of the components, making them more attractive and intuitive.
During these last sprints we also adapted the code to offer proper responsiveness, ensuring that elements display correctly on any device.

## Recently Incorporated Improvements
In this last sprint we completely redesigned the visual side, using the styles provided by the ESARDI team.
We changed the global colours, secondary colours and status colours, among others. We changed the font from Arial to Switzer and added animations and hover effects to buttons to improve the user experience.
We made use of components, which provides visual consistency across all components, making navigation more predictable.
We integrated Sienna Accessibility, an accessibility widget that allows users to modify visual aspects of the website in a simple way, which considerably improves the experience for users.
We also added a Switch to toggle between Light Theme and Dark Theme.
Finally, we added Tooltips so that users know what the buttons do.

## Future Improvements
Currently, depending on the form field, validations are only shown when clicking "save" or "book".
We want to change this to real-time validations.
